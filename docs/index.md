# QCM Analyst

**QCM Analyst** is a specialized web-based tool for real-time monitoring and analysis of Quartz Crystal Microbalance (QCM) experiments.

## Core Capabilities
* **Live Monitoring:** Connects to local data logs (e.g., from LabVIEW or Arduino) using the File System Access API.
* **Smart Calculations:** Automatically switches between Sauerbrey and Z-Match equations based on mass loading.
* **Data Cleanup:** Built-in tools for point decimation and removing experimental artifacts.
* **Portable Reports:** Export full experimental data and charts to a PDF report instantly.

## Quick Start
1. Open the `sauerbrey.html` file in a modern browser (Chrome or Edge recommended).
2. Click **Open File** or drag your data log directly onto the charts.
3. Configure your **Experimental Setup** in the sidebar (Frequency, Density, and Z-Factor).
