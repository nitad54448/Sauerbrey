# Operations Guide

## Navigation & Zoom
* **Toggle Zoom:** Click the **Zoom** button in the header. When active, click and drag on the chart to "box zoom."
* **Panning:** While zoomed, hold **Shift + Drag** to move through the timeline.
* **Reset:** Use **Reset View** to return to the full experimental scale.

## Analysis Cursors
When **Zoom** is **OFF**, you can interact with the vertical cursors:
1. **Green Cursor (Start):** Drag this to your baseline frequency.
2. **Red Cursor (End):** Drag this to your measurement point.
3. The sidebar **Results** panel will update in real-time with the thickness ($nm$) and rate ($nm/s$) calculated for that specific window.

## Data Management
* **Decimate:** If your log file is too large, use the **Decimate** button to reduce point density by 50% in the visible area.
* **Remove Visible:** Use this to delete "noise" or outliers from the dataset within the current zoom window.
* **Follow Live:** Enable this to keep the chart locked to the right-hand side as new data arrives.
